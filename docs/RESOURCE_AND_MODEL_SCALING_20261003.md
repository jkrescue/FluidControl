# 串联双圆柱控制：资源与模型扩展决策（2026-10-03）

## 科学目标与当前状态

保持 Re=100、L/D=5、仅后圆柱旋转的既定工况。最终验收是相对同相位零控制的前后圆柱总平均阻力降低至少 2%，后圆柱升力脉动均方根不超过基准的 1.05 倍，且后圆柱平均升力绝对值不超过基准升力脉动均方根的 0.1 倍；控制幅值与能耗另行记录。模型误差、优化器提出的动作以及真正的 CFD 验证必须分别报告。

截至本文，两相位长窗 OpenFOAM 已证实恒定 `omega=±1` 可降低总阻力约 3.6%–4.1%，但产生很大的后圆柱平均升力，联合目标失败。v3 H20 PhysicsNeMo FNO 的 100 步**终点瞬时**总阻力 pooled NRMSE 在验证集为 15.047%、冻结测试集为 16.172%，均未达 10% 门槛；它也尚未测量 100 步窗口**平均**阻力的误差。v4 长预测窗/低动作补充数据的训练仍在进行，不能预支其结果。

## 资源事实，而非只看显存占用

2026-10-03 04:30 UTC：Spark 主机和计算节点的 GPU 利用率约 95%–96%。Spark 的 `MemAvailable` 约 98 GiB；其 GPU 与 CPU 共用内存，`nvidia-smi` 的显存栏不能单独解释剩余容量。Spark 同时在跑 H20 模型训练和独立 CPU CFD；计算节点在跑 v4 单步对照训练。每台机器约 20 个 CPU 逻辑核。主机项目盘此前检查约有 588 GB 剩余，计算节点仅作临时计算，数据和最终记录回传主机。

当前模型：官方 PhysicsNeMo FNO，二维 128×256 网格，输入 6 通道、输出 7 通道，`latent_channels=48`、5 个谱层、`num_fno_modes=[32,32]`、解码宽度 128，H20 训练 batch 4，约 47.22M 参数。相同 API 下预估宽度 64/模式 32 为 83.94M 参数；宽度 64/模式 48 为 188.79M 参数；宽度 80/模式 48 为 294.98M 参数。这些只是**模型规模**，不是性能改进的证据。当前 GPU 算力利用率已高，扩大网络会增加训练时间；28 条训练轨迹即使有约 22,428 个时间相关帧，也不能当成同等数量的独立控制轨迹。

## 优先级和进入条件

1. **先完成严格验证。** v4 与 v3 在完全相同、未参与训练的四条验证轨迹上比较 1/10/50/100 步预测；同时报告 pooled 100 步终点总阻力和 100 步窗口平均总阻力误差，并保留原有五条冻结测试轨迹。只有这一关通过，才能相信代理模型做长期动作选择。不要用短窗指标替代长窗控制目标。
2. **若误差集中在低转速或相位外推，先补真实 CFD，不先堆参数。** 额外生成独立起始相位、带正负低幅值及分段动作的后圆柱旋转轨迹；将新轨迹只放训练集，原验证和冻结测试保持字节不变。CPU 节点可并行两条 OpenFOAM 任务，配置、初态哈希、Courant 数、力输出和数据清洗检查都与现有流程一致。计算节点只存临时文件，完成后复制原始数据和出处至 Spark，核验后删除计算节点临时副本。当前没有证据表明盲目增加同相位、相近动作的帧有用。
3. **若数据覆盖充分但仍欠拟合，做受控模型对照。** 在同一数据划分和训练预算下，先测试官方 FNO `latent_channels=64, num_fno_modes=[32,32]`；若高频误差仍主导，再试 `[48,48]`。除网络规模外保持损失、预测窗和种子可比。每次先运行短时吞吐/内存测试，持续检查 Spark `MemAvailable>20 GiB`，并以每秒有效样本数、长窗误差和真实 CFD 控制效果决定是否保留。batch 4→8 只能作为吞吐消融；较大 batch 不会增加独立流动条件。
4. **暂不把 FNO3D 当作当前二维算例的“升级”。** 官方 `FNO3D` 接收 3 个空间维度；本例物理域是二维。把时间硬当第三空间维度会改变输入/输出、训练目标与因果预测契约，不能沿用现有 checkpoint。若将来研究真正三维流动或专门设计时空块模型，应作为单独课题与算例，而不是现在的直接放大。
5. **暂不把自写 FNO+局部卷积/UNet 混合体放入主线。** 文献支持局部结构与谱算子的组合，但这不是现有官方 FNO 的配置开关；用户要求使用 PhysicsNeMo 官方模型/API、避免自创模型。官方 AFNO、DPOT、Seq2SeqRNN 可列为后续独立基线，在验证数据量与输入尺寸兼容后再评估。DPOT 官方示例针对方形二维网格，当前 128×256 不能直接照搬。

## 与 2024–2026 研究的关系

- 港理工 Zhao、Tang 等的 [2024 年尾流圆柱深度强化学习工作](https://research.polyu.edu.hk/en/publications/mitigating-the-lift-of-a-circular-cylinder-in-wake-flow-using-dee/) 主要关注后方圆柱升力波动抑制。我们添加了**总阻力与平均升力联合约束**，所以不能直接把它报告的升力抑制效果等同于本项目完成。
- 港理工团队的 [2024 年 FNO/U-Net 混合湍流预测论文](https://ira.lib.polyu.edu.hk/bitstream/10397/111435/1/PhysRevFluids.9.084604.pdf) 说明局部结构可能改善长时间预测，但其三维湍流通道与当前二维串联圆柱及后柱旋转控制并不相同；需要控制变量实验，不应直接迁移结论。
- [2025 年模型辅助主动流动控制论文](https://doi.org/10.1063/5.0287427) 重视多步预测与模型偏差；[2025 年 CFD/代理交替训练论文](https://www.sciencedirect.com/science/article/pii/S0952197625024996) 给出减少高成本交互的例子。这支持本项目“先测长窗误差、再用 CFD 验证并补有信息量的样本”的路线，但并非现成的本工况性能保证。
- [2026 年两阶段模型控制预印本](https://arxiv.org/abs/2609.08436) 使用稀疏压力观测控制 Re=100 单圆柱尾流，提示论文下一阶段应认真比较“短时转移 + 局部反馈稳定”的闭环架构。但它是近期预印本、单圆柱且控制器/动作不同，不能把其降阻数字迁移到串联双圆柱案例。
- 官方 [PhysicsNeMo FNO 文档](https://docs.nvidia.com/physicsnemo/26.03/physicsnemo/api/models/fnos.html) 列明可用的维度与参数。本项目继续以官方实现为准，任何新 API 都先在固定镜像里验证。

## 近期执行判据

当前两台 GPU 已经在做不同的受控对照，不增加并发 GPU 任务以免争抢计算资源。待 v4 验证完成，如果 100 步总阻力误差仍超过 10%，且主要错误来自未覆盖的低幅值/相位动作，就启动计算节点 CPU 上的少量**预先定义** OpenFOAM 新轨迹；如果主要是已覆盖区域的系统性欠拟合，则做官方 FNO 宽度/模态消融。任何模型或数据扩展都必须在原冻结集及真实 CFD 联合控制指标上证明增益，才纳入论文主线。
