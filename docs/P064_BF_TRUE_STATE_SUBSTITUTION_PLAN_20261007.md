## Question and non-repetition

and original-six AR retention. Test whether the B/F difference remains when
every current state is true CFD rather than frozen-flow prediction. This is a
realized-action conditional diagnostic, not online forecasting, new training,
or proof that flow is the sole cause. Existing E073 used dynamic6/H100/highTF32;
E094 only six initial states; neither supplied this exact controlled16×H5
matched true-current-state counterpart. Existing E099 freeAR is reused intact.

## Analysis and decision

Report all four coefficients plus signed-sum totalCd MAE/RMSE/bias, every lead,
phase and pooled, for true-state, savedAR and original hold-current persistence.
No selection of favorable origins or leads; do not subtract MAEs as a causal
decomposition. If F also degrades on true states, shortAR adaptation is not
supported by this test. If true-state F improves but freeAR F degrades, that
supports preparing a separately approved state-distribution matching experiment,
not automatic training/PPO/CFD or scientific admission. Preserve original rules.
