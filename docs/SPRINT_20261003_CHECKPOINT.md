# 2026-10-03 两小时冲刺检查点

## 目标仍然是什么

在 Re=100、L/D=5 的固定串联双圆柱中，仅旋转后圆柱；用真实 OpenFOAM CFD 证明前后两柱**平均总阻力至少下降 2%**，后圆柱升力脉动不超过零控制的 1.05 倍，平均后柱升力绝对值不超过零控制升力脉动均方根的 0.1 倍。动作幅值、变化速率和力矩功率代理要单列。PhysicsNeMo FNO、HydroGym 和 PPO 只负责预测/决策过程，不代替真实 CFD 验收。

## 为什么暂不放大网络

当前官方 FNO 约 47.22M 参数。宽度 64/模式 48 会约 188.79M 参数，但训练轨迹只有 28 条，v4 续训已证明增加少量数据/轮数并不自动改善长窗误差。现有四条验证轨迹在 100 步尺度上没有一个完整的 `max|omega|≤1` 片段，恰是目标动作范围的证据缺口。先完成独立低动作验证，确认误差来源，再决定要增加训练 CFD 轨迹或做官方 FNO 宽度/模态对照；FNO3D 并非当前二维算例的直接替代。
