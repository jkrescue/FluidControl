# PhysicsNeMo 流动控制第一阶段结果

截至 2026-09-27：**真实流场代理模型已跑通；最优控制预测尚未达标；HydroGym 暂不启动。**

项目采用[公开实验数据](https://doi.org/10.5281/zenodo.20794709)，而非虚构流场：28 个后圆柱对转控制量，29 份受控 PIV 文件（其中 `p=−1.4` 有额外向上尾流分支），约每组 1800 帧，以及实测阻力。28 份 `_zero` 文件其实是无控制参考，虽然 HDF5 属性写着后续对应的控制量，处理程序已识别并排除，避免错误标签。原始数据校验和、处理后数据检查均通过；但原始 `Uncertainty` 数组全部是 `NaN`，不能报告逐工况误差条。

使用远程 GPU 0 上隔离的 `nvidia-physicsnemo 2.2.2` 环境，将完整控制量 `p=±1.8` 留作测试，`p=±1.0` 留作验证，其余 24 个工况训练。PhysicsNeMo FNO 对 0.1 秒后时序速度场的测试 MAE 为 `0.0669 U∞`，优于保持当前场不变的 `0.1243 U∞`，也优于邻近工况时间平均场插值的 `0.1218 U∞`。另一个从**已经观测到的** PIV 流场估计阻力的 FNO，在 `p=1.8` 的阻力预测为 `1.210`，实测 `0.926`；两组测试工况的阻力 MAE 为 `0.378`，优于仅根据控制量做线性插值的 `0.482`。这支持“流场预测＋观测到阻力的估计”两项技术能力，但观察器不是反事实控制器。

直接从控制量预测平均场／阻力的模型尚不可靠：模型找出的低阻力控制约 `p=1.45`，而实验最低阻力在 `p=1.8`；两组未见工况的平均场误差也高于简单插值。把推荐量取到已实测的 `p=1.4` 时，阻力从无控制 `3.017` 降至 `1.051`，但 `p=1.4` 本来就在训练集，不能宣称模型发现了新最优点。阶段一尚不能标记为“完整的最优流动控制复现”。

自编谱方法已生成 48 组二维 CFD 开发数据和[配置说明](CFD数据生成说明.md)，但网格加密造成约 `9%–10%` 指标变化，未通过网格独立性。它们被程序强制标记为未验证，未进入上述正式模型训练。下一步应优先完成独立 CFD 求解器的受控旋转工况与网格／时间步验证，或进一步扩大公开实测控制数据上的留出评估；在此之前不进入 HydroGym 阶段。
