# 当前目标完成差距审计（2026-10-06）

## 结论先行

**固定 Re100、L/D5、后圆柱旋转的简单数值闭环已真实跑通，并在 b00、b01、b03 三个观测初相位满足原 primary 物理约束。** 这不是训练空转、离线轨迹伪装反馈，也不需要把均值升力限制从10%放宽到20%才能成立。除模型长滚动正式失败及下述范围限定外，没有发现尚未执行的必需端到端接口。跨 Re、主动学习、MPC、物理实验实时部署不是这个有限场景的新增必需条件。

但不能把它写成“所有正式研究门槛均已通过”：当前 K1 的 **H100 development/formal FAIL 仍真实存在，已受控轨迹上的短时受力预测也有明确不足**。成功控制器是“FNO 环境训练的 PPO + 显式镜像投影”，不是未经处理的 PPO，也不是每个真实控制周期都运行 FNO 的控制器。短时代理的范围性接受与 H100 正式接受必须分开。依据 AGENTS 的“accepted surrogate”要求，若“完成”指所有历史正式门槛均通过，项目尚不能这样宣布；若指用户目前要求的固定场景简单闭环，则操作链与物理效果已有实证，不能因模型失败而否认这些成果，也不能反过来把控制收益等同高精度代理全面完成。

本审计只读取源码、已有报告及进程元数据，没有训练、CFD、模型重载或新的测试集访问。查询时研究训练/CFD单位均无 running；dashboard/watchdog仍运行。

## 必需差距与非必需扩张

1. **不是缺失接口：** CFD→当前状态/采样、官方模型加载、真实HydroGym/SB3优化、最终策略→真实CFD反馈均已有实际执行证据。无需为证明这条有限链再次建框架或增加同类前置探针。
2. **真实未解决：** K1 H100正式长预测失败；范围外动作/状态、跨配置稳健性和统计独立泛化未证明。不能把这些写成零误差或已接受，也不能把可选泛化当作当前固定场景闭环不存在。
3. **需准确命名而非新训练：** 成功的是固定PPO加镜像投影控制器。投影是明确的项目后处理干预，真实CFD检验了组合效果；不能称未投影PPO原样通过，也不能将成功全部归于FNO精度。
4. **最近的收尾工作：** 80端点独立NPZ重算已经完成；保留已确认的受控分布误差，完成固定start0/700的H1/H5预测/真值/误差可视化与归档。不自动调参或重开最终测试。
