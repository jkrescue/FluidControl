# FNO 控制相关受力窗口诊断

## 为什么增加这一项

原有 H100 末端瞬时总阻力误差，不能直接证明模型能准确预测强化学习所使用的连续时间窗口。新增诊断检查一个固定窗口中的平均总阻力、后柱平均升力和后柱升力波动，保留每一步预测受力，便于核对。

这不是新训练目标，也不改变原来的模型选择、误差门槛或最终物理验收标准。

## 固定方案

- 数据：既有 dynamic6 验证集全部六案，b01/b05 的 minus/zero/plus，均从第 0 帧开始；不读取冻结测试集。
- 每案连续自回归预测 100 步，每步 0.1D/U；中途不输入真实流场修正预测。
- 动作使用该真实 CFD 轨迹已有的转速端点及线性变化约定，不重新挑选动作。
- 统计最后 6.15D/U 请求窗口内的已采样受力，共 62 个采样点，实际首末采样点相隔 6.1D/U；这是样本统计，不称为连续 6.15D/U 积分。报告平均总 Cd、后柱平均 Cl、后柱波动 Cl RMS，以及各动作相对同起点零转动的平均总 Cd 差值。汇总的 `mean_action_delta_error` 仅是四个动作对的平均总 Cd 差值误差，不代表四个受力通道的总体精度。
- 对照模型固定为 B-e5 父模型和本轮 H50 原有验证规则选定的不可变 checkpoint。新增结果不参与 checkpoint 选择。
- 同步记录每一步有效流体单元上的预测/真值压力空间均值、原始压力相对 L2、仅为诊断而分别去均值后的压力相对 L2，以及 `(u,v)` 联合相对 L2；每案保留100行并汇总最小、最大、均值和H100终值。
- 先完成正在运行的训练及正式全套后评估，再执行此诊断；不抢占当前训练 GPU。

## 解释限制

这里是 0.1D/U 采样下的短窗口代理模型诊断，不是采用 0.005D/U CFD 受力记录的最终 60D/U 减阻验收；不能直接据此声称控制成功或授权代理模型 PPO。

数据整理时每帧压力已减去有效流体域空间均值，但当前训练、正式评估和 HydroGym 递推均只重新乘 mask，没有逐步再次投影压力均值。因此存在可观测的 pressure-gauge drift 风险；它尚未被证明是长时误差的原因。新增去均值压力误差只作用于复制出的诊断数组，绝不写回递推状态、不改变力头、不替代原始压力或正式指标，也不改变模型、训练或门禁。

原始 HDF5 的 time 为 float32 列向量。约 t=130 时，相邻采样差会有约 1e-5 的量化误差，插值动作也有约 6e-6 的差异。读取时仅展开维度，检查时允许 2e-5 的数值表示误差；不重写时间、不修改动作、不重采样数据。

## 实现验证

`scripts/diagnose_fno_force_window.py` 使用现有官方 PhysicsNeMo FNO 构建/载入入口，无新增模型。CPU 单元测试还覆盖压力常数偏移只影响原始压力误差、不影响诊断去均值误差，mask 排除固体单元，非有限/错形拒绝，以及逐步范围汇总。实际六个 HDF5 的数据标识、时间、动作、固定几何、配对初始场和真值压力均值范围已通过 CPU 预检：六案各前101帧的有效域真值压力均值全局范围为 `[-1.4911e-9, 1.6553e-9]`，符合逐帧 gauge 预处理。完整模型推理需在训练结束后的诊断任务中验证，不能将预检称为推理完成。

排队入口：`scripts/run_fno_force_window_after_training.sh`，先 dry-run，再显式 execute。当前训练或全套后评估失败时停止，不自动改用别的模型。所有推理保留至少 20 GiB 可用统一内存，记录模型、脚本和数据 SHA-256。
