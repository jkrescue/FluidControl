### 已完成验证与结果

无控制粗网格和中等网格均采用二阶时间格式与 `Δt=0.005`，在预先固定的 `t=80..160` 比较：

| 指标相对差异 | 前圆柱 | 后圆柱 |
| --- | ---: | ---: |
| `Cd_mean` | 0.4635% | 0.0476% |
| `Cl_rms` | 1.5567% | 0.5012% |
| `St` | 0.8055% | 0.8001% |

32 个探针的最大绝对差为：速度均值 `u=0.0172、v=0.00807`，速度 RMS `u=0.01542、v=0.01220`。主要受力指标低于预先设定的 3% 粗／中网格门槛。`omega=+1` 旋转代表工况也已完成粗／中网格比较：前柱 `Cd_mean/Cl_rms/St` 差异为 `0.4982%/2.4643%/0.7945%`，后柱为 `0.1560%/1.0616%/0.7928%`；探针最大绝对差为均值 `u=0.02451、v=0.00673`，RMS `u=0.02399、v=0.01367`。旋转工况主要受力指标同样通过 3% 门槛，因此开放 Curator 步骤。

恒定动作 `omega=-1,-0.5,0,+0.5,+1` 的 5 条粗网格轨迹已完成。每条 `t=0..160`、32,000 个求解步、1,600 个 `U/p` 场快照、前后圆柱各 32,000 条力系数和 32 点探针各 32,000 个时刻，单条约 4 GiB。五条均通过基本数值质量检查。

动态轨迹从已验证无控制解的 `t=80` 重启，在 `t=80..160` 施加 `omega(t)∈[-1,1]`。共 16 条：12 train、2 validation、2 test；每条 16,000 个求解步、801 个场快照、800 个相邻帧对。动作类型包括随机分段线性、多正弦、训练中未出现的四分之一档位和 chirp。16 条已全部正常结束并通过逐文件只读检查：总计 256,000 个求解步、12,816 个 `U/p` 快照、256,000 个探针时刻，最大 Courant 数 `0.251260868`，逐步全局连续性误差最大绝对值 `1.93218635e-12`，原始数据约 32 GiB。正式结果位于 `artifacts/tandem_cylinders/dynamic_dataset_manifest.json`。

### 面向 PhysicsNeMo 的最终规模

5 条恒定轨迹只截取 `t=80..160`，与 16 条动态轨迹一起按完整轨迹划分：train 15、validation 3、test 3；对应一步样本 12,000、2,400、2,400。使用 `foamToVTK` 导出原始 `U/p`，再由 PhysicsNeMo Curator 的 `Source → Filter → Sink` 脚本采样为 `256×128` HDF5。具体命令、字段形状、归一化、PhysicsNeMo `HDF5Reader` Datapipe、FNO 训练和测试见项目根目录 `train_recipe.md`。

这一规模可用于第一阶段的动作条件短时场代理模型和训练链路验收。它只覆盖二维、单一 `Re`、单一 `L/D` 和 `|omega|≤1`；不能支撑跨工况工程模型，也不能在没有 CFD 闭环回放的情况下证明控制策略有效。

## 一、场景与数据分层

目标场景是一个上游主圆柱、两个下游旋转控制圆柱的绕流控制。港理工叶伟健／唐辉论文中的具体实验几何、雷诺数与下述开发求解器**不相同**，因此目前不宣称复现了港理工原实验。

正式的真实数据基准选用 Rodríguez-Asensio 等人 [2026 年论文](https://arxiv.org/abs/2602.17713)及其[公开数据集](https://doi.org/10.5281/zenodo.20794709)：三个等直径圆柱构成“流体弹珠”，前圆柱固定，后两个圆柱等速反向旋转；水槽实验 `Re=9100`。数据包含 28 个控制量下的时序 PIV 速度场与实测阻力。论文附带的 URANS 阻力表可读取；其涡量 `.hsf` 是可视化格式，不能冒充数值网格。Zenodo 三个原始文件已通过文件大小、MD5 和 ZIP 完整性校验，见 `artifacts/source_verification.json`。

自生成 CFD 是**独立的开发层**：48 组谱方法模拟已经运行，但未通过网格独立性，因此不进入正式 PhysicsNeMo 训练集。数据元信息明确写有 `status=developmental_unvalidated`；有关训练脚本默认拒绝它，只有显式加 `--allow-development-data` 才能做探索试验。

## 二、自生成 CFD 的求解器和配置

代码：`src/fluid_control/cfd.py`；批量入口：`scripts/generate_dataset.py`；数值敏感性检查：`scripts/verify_cfd.py`。这是项目内实现的二维不可压 Navier–Stokes 伪谱／Fourier 投影求解器，配合 Brinkman 速度罚法描述静止和旋转圆柱，**不是 SU2、OpenFOAM、DNS，也不是港理工论文所用求解器**。

| 配置项 | 当前设置 |
| --- | --- |
| 无量纲参考量 | 主圆柱直径 `D=1`、来流速度 `U∞=1`；`Re=100`、运动黏度 `1/Re` |
| 计算域与网格 | `[0,12D)×[-3D,3D)`；均匀 `256×128` 点，间距 `0.046875D` |
| 几何 | 主圆柱半径 `0.5D`、圆心 `(3D,0)`；两个控制圆柱半径 `0.125D`，分别位于主圆柱后方约 `±45°`；圆柱表面间距 `0.125D` |
| 控制量 | 两个独立有符号表面速度比 `q₁,q₂∈[-2,2]`；角速度 `ωᵢ=qᵢ/0.125D` |
| 边界与固体 | 两个方向均为 Fourier 周期边界；入口和出口附近加入松弛区；圆柱用平滑掩码和 `η=0.02` 速度罚法。**并非严格的水槽入口／出口边界条件** |
| 数值格式 | 非线性对流显式，黏性 Fourier 隐式阻尼，不可压投影，2/3 去混叠；时间步 `Δt=0.005D/U∞` |
| 运行与取均值 | 共 3600 步（`18D/U∞`），从第 2000 步开始平均；9 个固定控制锚点及随机种子 `20260927` 采样，总计 48 工况 |
| 硬件 | WSL 内独立 Python `.venv`；仅 GPU 0 加速 FFT；PhysicsNeMo 环境与其他环境隔离 |

重现当前**开发数据**的命令：

```bash
cd '~/workspace/fluid_control'
CUDA_VISIBLE_DEVICES=0 .venv/bin/python scripts/generate_dataset.py \
  --out artifacts/cfd_dataset.npz --count 48 --batch 8 \
  --nx 256 --ny 128 --dt 0.005 --steps 3600 --average-start 2000
CUDA_VISIBLE_DEVICES=0 .venv/bin/python scripts/verify_cfd.py
```

## 三、生成的数据字段

`artifacts/cfd_dataset.npz` 保存 `actions[N,2]`、时间平均 `fields[N,3,64,128]`、输入特征 `features[N,6,64,128]`、`wake_error[N]`、`control_cost[N]`、`objective[N]`。`fields` 的三通道依次为平均 `u`、平均 `v`、平均 `(u−1)²+v²`；不是压力，也不含圆柱受力。`wake_error` 为尾流指定窗口内速度偏离来流的平均量；`objective=wake_error+0.01(q₁²+q₂²)` 是自定义尾流代理目标，**不是阻力系数**。参数、种子和状态保存在同名 `.json` 中。

已生成样本的无控制 `objective=0.751853`，48 组中最低为 `0.667853`；这些数值只说明求解程序产生了不同响应，不构成物理控流改进证据。

## 四、当前验证结论及使用限制

在相同 `18D/U∞` 时长对 `(q₁,q₂)=(0,0),(1,-1)` 作了网格和时间步检查：网格由 `256×128` 加密至 `384×192` 后，尾流指标分别改变约 `9.9%`、`8.7%`；时间步减半后改变约 `0.04%`、`0.20%`。因此**网格独立性未通过**。此外 `18D/U∞` 未证明达到统计稳定，也没有给出与文献 Strouhal、平均阻力或同几何实验的比较。完整记录见 `artifacts/cfd_sensitivity.json`。

只有在补齐更长时程、网格／时间步收敛、不可压残差、圆柱壁面泄漏、基准 Strouhal／阻力和同几何实验对照后，才能把自生成 CFD 作为正式训练数据。现在正式结果只使用已核验的公开 PIV 实测场；不能把当前谱方法数据或 Fluent `.hsf` 图片称为“验证过的 CFD 训练集”。

外部开源 CFD 备选已筛查 [OpenFOAM 三圆柱案例](https://github.com/darshan315/fluidic_pinball)：其现有网格把三个圆柱合并为一个 `noSlip` 边界，不能直接表示两个圆柱独立旋转。要生成受控工况，须拆分壁面 patch、设置相反符号的旋转壁面速度、固定容器版本并重新做网格和力系数验证。此路线**尚未运行**，不可与上述 48 组谱方法数据混称。
