# Current-frame shadow adapter: bounded CPU preparation

Project code only; no official API replacement or execution approval. Fixed Re100, L/D5, rear rotation only. Existing `sample_tandem_vtk_frame.py` remains the external Curator producer; no resampling or pressure regauging is added. Existing controls and official DatasetBase/HDF5Reader remain untouched.

Contract: consume only the producer's five arrays (state, mask, time, x, y), with float32 physical state [3,128,256], uint8 binary mask [1,128,256], exact float32 grid x=linspace(8,25,256), y=linspace(4,11,128), and a single finite time matching caller-declared completed CFD time within the existing sampler-feedback tolerance 1e-5. Require caller-bound expected mask equality, finite state and zero solid cells. Inputs contain no following frame, force label or future truth. Packet provenance remains the future orchestrator's responsibility: this interface validates contents, not CFD authenticity.

Verify raw train-normalization JSON bytes against an externally supplied SHA256 before parsing; require state channels u,v,gauge_pressure and three finite means/positive standard deviations. Apply the exact existing FP32 formula `(physical - mean) / std * mask`; do not recompute normalization or pressure gauge. Return detached CPU normalized state [1,3,128,256], mask [1,1,128,256], time and normalization digest.

Separate K1 packing accepts actual applied omega at t and a separately selected, already constrained command for t+0.1. Reject nonfinite/out-of-support/rate-violating values; never clamp or select actions. Reuse pinned `p026_state_history.build_input` with both actions divided by .75, yielding [1,6,128,256]. Official FNO still appends its own coordinates. K4 history and autonomous action selection are explicitly out of scope.

Synthetic CPU tests cover exact normalization and packing, no mutation, norm SHA failure, bad grid/mask/time/shape/nonfinite packets and action ordering/constraints. No real VTK/HDF/model/CFD/GPU execution. A future separately approved one-frame Curator check must compare against curated data and measure extraction latency; shadow predictions are not accepted force predictions, MPC/PPO admission or physical closed-loop success.
