# 总体技术方案

## 目标与场景

构建“真实 CFD 数据—神经代理—控制策略—真实 CFD 反馈”的串列双圆柱主动流动控制案例。降低两柱总平均阻力，同时限制后柱升力波动、平均侧向力及动作变化。

当前限定 Re=100、L/D=5，前柱固定，后柱绕固定中心旋转；无结构运动。D=U∞=ρ=1，运动黏度 ν=0.01。无量纲转速 ω*=ΩD/U∞，与表面线速度比 ΩR/U∞ 相差两倍。

## 技术架构

![训练与验证架构](../research_records/assets/training_vs_deployment.svg)

| 层次 | 输入与工作 | 交付与状态 |
|---|---|---|
| CFD 数据 | OpenFOAM 求解速度、压力、受力及动作 | 已生成并核查数据；网格/时间步独立性仍需完善 |
| 数据处理 | VTK → 官方 Curator → HDF5；官方 Reader 与项目 DataPipe 组织窗口 | 已接通；保留来源、时钟、划分及训练归一化 |
| 代理模型 | 官方 PhysicsNeMo 双 FNO 分别预测流场与圆柱受力 | 保留 B；完整预测精度未通过 |
| 策略训练 | HydroGym 接口调用项目 FNO 推进器；SB3 PPO 交互学习 | 已训练 E082，32,768 次交互 |
| 数值闭环 | 固定 CPU PPO 读取 CFD 观测，控制后柱，再推进 OpenFOAM | E095 复现及 E114 延长时段通过物理标准 |
| MPC 探索 | FNO 评价候选转速，执行第一步，再读取 CFD | 已完成短试验，未证明减阻有效 |

官方组件与项目适配代码分别标识。OpenFOAM 不属于 PhysicsNeMo；PPO 不由 HydroGym 提供；本项目没有使用一个自动完成全部环节的官方示例。

## 分阶段实施路线

1. 保留基线和证据：固定代码、模型、策略、数据划分及评价方法，分别记录工程完成、预测精度和物理控制效果。
2. 数据与代理诊断：核查动作时间对齐、归一化、受力标签及状态覆盖，区分单步、长时递推和动作响应误差。
3. 验证针对性改进：每次围绕一个可检验假设修改数据或训练方式，与同精度、同窗口的 B 比较；不能仅凭训练损失选择候选。
4. 控制比较：保留 PPO，增加无旋转、固定旋转等简单基线，再评价预测可靠后的 MPC 和兼容的新策略。
5. 真实 CFD 验证：配对反馈、完整预定窗口与独立重复；补充网格、时间步及能耗研究。

这是后续组织方案，不表示各阶段都已完成。主动学习、多 Re 泛化和不确定性修正尚不是已实现能力。

## 研究管理

Lead 负责范围、实验决策和整合；数据、代理、控制和独立评价各承担明确职责。每个实验记录假设、父模型、代码/配置版本、数据划分、指标、结果与下一步。当前整理不新增训练或改变物理标准。
