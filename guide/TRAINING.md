# 代理模型与训练

## 数据组织

数据来自真实 OpenFOAM，不使用示意场作为训练真值。CFD 积分间隔为 0.005 D/U∞，模型帧与控制间隔为 0.1 D/U∞，每帧对应 20 个 CFD 时间步。

PhysicsNeMo Curator 将 VTK 网格场采样、整理为 HDF5；官方 Reader 与项目 DataPipe 构建相邻时刻及连续窗口。采样区域为 x=[8,25]、y=[4,11]，分辨率 128×256，不是 CFD 原始网格。归一化统计只来自训练数据，开发与评价不重新拟合统计。

## 网络结构

采用 PhysicsNeMo 2.2.2 官方二维 FNO；两个网络结构相同、权重独立，分别用于流场和气动力预测。

![FNO 网络计算结构](../research_records/report_20261007/assets/fno_network_structure.svg)

| 配置 | 实际值 |
|---|---|
| 输入 | 6×128×256：u、v、压力、流体 mask、当前转速、下一步指定转速 |
| 官方坐标增广 | 加入两个相对坐标通道，6→8 |
| 升维 | 1×1 卷积 8→24→48 |
| 主干 | 5 层二维谱卷积 + 局部 1×1 卷积；模态 32×32 |
| Padding | 两个空间轴末端各补 8，再裁去 |
| Decoder | 48→128→128→7，两个隐藏层 |
| 原始输出 | 3 个流场增量通道与 4 个受力读出图通道 |

项目程序还原流场增量，对受力读出图做 mask pooling，得到前柱 Cd/Cl 与后柱 Cd/Cl；不是直接对粗网格压力积分。下一步转速是控制已指定的输入，不是未来真实流场。

## 保留 B 的有效训练配置

以下仅描述 B 从已有 K1 权重继续训练的这一轮，不是全项目从零训练的总步数。

| 项目 | 实际设置 |
|---|---|
| 数据窗口 | 256：原训练 192 + 受控 b00 64 |
| 每窗长度 | 100 个预测端点 |
| 更新次数 | 32 次 AdamW 更新，梯度累积 8 个窗口 |
| 学习率 | 1.5625×10⁻⁷ |
| 优化范围 | 流场网络冻结；受力网络更新 28 个参数张量，两个升维 bias 冻结 |
| 目标 | 0.5×单步监督误差 + 0.5×连续 100 步递推误差 |
| 受力权重 | 前 Cd / 前 Cl / 后 Cd / 后 Cl = 0.125 / 0.125 / 0.125 / 0.625 |

单步监督使用真实当前流场；连续递推使用上一步预测继续推进。评价分开报告流场、受力、总阻力、后柱升力波动及动作响应。

## 当前评价结论

B 已用于训练有效的限定工况 PPO，但完整预测评估未通过。Representative256 虽然降低训练拟合损失，在同精度固定六窗口上单步/连续误差分别增加 15.82%/14.27%，未替换 B。受力训练损失下降不能描述为流场网络精度提高。
